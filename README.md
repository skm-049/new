## 🛠️ Installation

To set up the portfolio locally:

1. **Clone the Repository** 📥:
   ```bash
   git clone https://github.com/yourusername/mr-skm-portfolio.git
   cd mr-skm-portfolio
   ```

2. **Install Dependencies** 📦:
   ```bash
   npm install
   ```

3. **Set Up Environment Variables** 🔑:
   Create a `.env.local` file in the root directory:
   ```env
   NEXT_PUBLIC_EMAIL_SERVICE_ID=your_service_id
   NEXT_PUBLIC_EMAIL_TEMPLATE_ID=your_template_id
   NEXT_PUBLIC_EMAIL_USER_ID=your_user_id
   ```

4. **Run the Development Server** ▶️:
   ```bash
   npm run dev
   ```
   Access the site at [http://localhost:3000](http://localhost:3000).

5. **Build for Production** 🏗️:
   ```bash
   npm run build
   npm run start
   ```
